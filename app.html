      THE THINKING BEHIND THE STUDIO

      Same concept.
      A path that fits.

      Every level explores one core idea: finding the values that make a quadratic equal zero. A shared seed connects the equations when you switch levels.

      01 / Foundation

      Factor a monic quadratic with integer roots. Get a direct, three-step scaffold and progressive hints.

      02 / Standard

      Handle a non-monic quadratic with irrational roots. Use the discriminant and quadratic formula.

      03 / Advanced

      Model a ball’s height. Interpret the physical root, find the vertex and calculate the maximum height.

      How the AI works. An open-source SmolLM2 language model runs in a background worker on your device. The first request downloads its model files. It chooses among verified next-step, concept, checking and connection cards using your question, level and equation. Its output is restricted to four valid choices; all displayed mathematics comes from the verified task engine.

      No account, API key or student data upload is required. Model files need an internet connection initially; the browser may cache them. On unsupported devices, verified hints and walkthroughs remain available. Progress is stored locally on this device.
